TIAXORA — Version 4 (prototype local)

Cette version ajoute :
- un formulaire de demande pour devenir vendeur ;
- un espace de gestion de démonstration pour approuver/refuser les demandes ;
- un formulaire administrateur pour ajouter tes propres annonces ;
- la modification du prix et la suppression des annonces créées dans la démo ;
- les annonces ajoutées sont affichées dans le catalogue ;
- les boutons de détail ouvrent WhatsApp avec un message prérempli.

IMPORTANT : ce n'est PAS encore une vraie marketplace en ligne.
Les données sont stockées dans le localStorage du navigateur sur cet appareil uniquement. Elles ne sont pas partagées avec d'autres visiteurs et peuvent disparaître si les données du navigateur sont effacées. L'espace administrateur n'est pas sécurisé et ne doit pas être utilisé avec de vraies données sensibles. Aucun compte réel, backend, paiement, commande ou transfert de billets n'est actif.

Pour une vraie version, il faudra héberger le site et connecter une base de données/backend avec authentification sécurisée, rôles, gestion des commandes, vérification des vendeurs et prestataire de paiement compatible.
